# Fix a transaction from a report

## What this solves

A figure in a report looks wrong — too much under Groceries, say — and you want to find the
transaction behind it and correct it on the spot.

## Steps

1. Open **Reports**.
2. Tap the category in **This month**, or tap the amount in a month's column in **By category**.
   The transactions behind that figure open in a list.
3. Tap the transaction you want to change. It opens for editing — change the amount, category,
   account or date.
4. Tap **Save**. To remove it, hold **Delete** until it fills.

## What success looks like

- The list under it updates right away: a new amount shows, and a transaction moved to another
  category leaves the list.
- The report's figures change to match once you close the list.

## If it doesn't work

- **Nothing happens when you tap a category total in the table** — tap a month's amount instead;
  the Total column isn't a list.
- **The change is undone a moment later** — someone else edited the same transaction at the same
  time on another phone; the later edit wins. Open it again and check.
